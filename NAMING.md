# NAMING.md

Canonical names for every company, adviser, person and system default in the game.
Use these instead of inventing new ones. If you need a name that isn't here, ask
before creating it.

---

## Rules

1. **Never explain a name.** No tooltips, no lore entries, no "fun fact" text. Every
   name below must read as ordinary corporate furniture to a player who does M&A for
   a living. If a name draws attention to itself, it's wrong.
2. **No first names for the seller side** unless listed. Surnames and places only.
3. **Names are load-bearing, not decoration.** Each adviser below has a mechanical
   function. Implement the function; the name is just the label on it.
4. **Consistency across saves.** The same entity keeps the same name in every
   scenario. Avonmouth is always Avonmouth.

## Advisers and counterparties

Each has a mechanical role. The role is the point; the name is the label.

| Name | Role | Mechanic |
|---|---|---|
| **Masego Capital** | Rival bidder (PE) | Competing buyer in auction processes. Disciplined. Walks on price rather than overpaying. |
| **Bellion Partners** | Sell-side bank | Runs the auction. Controls information flow and timetable pressure. |
| **Monk Forensic** | Financial diligence | Premium option. Thorough to the point of obstruction — surfaces real red flags but slows the timetable and burns budget. Tagline: *it's a gift and a curse.* |
| **Destin & Conrad LLP** | US counsel | Buy-side legal on cross-border deals. Drafting quality affects which warranties survive. |
| **Tanerélle Office** | Rival bidder (family office) | Strategic acquirer. Irrational on price when the asset fits the portfolio — the one that outbids you. |
| **Santa Barbara Advisory** | Commercial diligence | Cheap option. Projections are confidently produced and weakly sourced. Player is not told which. |
| **Linetti Communications** | PR / comms | Manages announcement and leak risk. More interested in its own profile than the deal outcome. |

**Design note.** Santa Barbara vs Monk Forensic is the core diligence trade-off:
cheap-and-confident against expensive-and-slow. Neither is labelled as the correct
choice. Santa Barbara's output should look identical in format to Monk's — the
difference only surfaces post-closing.

## System defaults and furniture

- **Long stop date** defaults to **23 March** of the following year.
- **Dataroom index numbers** run from **2403**.
- **Disclosure bundle** is labelled **the Exposé** throughout the UI.
- **Save files** are called **Chronicles** (e.g. `Chronicle 03 — Project Holland`).
- **Difficulty tiers**, in order:
  1. **Clean Team** — full disclosure, generous budget, seller negotiates in good faith.
  2. **Red Flag** — partial disclosure, constrained budget, seller withholds.
  3. **Shutter Island** — seller has buried the liability *and* the diligence report
     is actively wrong. Player cannot reach ground truth before signing.

---

## Do not

- Do not add explanatory copy to any name.
- Do not create an in-game glossary that decodes them.
- Do not use any of these names for achievements, loading-screen text or marketing.
- Do not reuse a target name as an adviser name or vice versa.
